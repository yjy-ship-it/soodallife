수달 라이프 V124 검색·세무원장·광고 타기팅 배포본

R2 수정
- SQL Server가 같은 배치에서 새 컬럼을 미리 해석해 적용을 중단하던 문제를 동적 SQL 경계로 수정했습니다.
- 엔터티 설정과 DB의 문자열 길이 및 decimal 정밀도를 일치시켰습니다.
- 최초 V124 실패는 트랜잭션 롤백 및 파일 배포 전 중단이므로 R2를 그대로 재실행할 수 있습니다.

R3 수정
- 추가 전용 wallet_ledger의 기존 행을 갱신하지 않도록 변경했습니다.
- 과거 원장은 LEGACY_UNSPLIT으로 보존하고 배포 이후 생성되는 원장부터 공급가액·VAT를 기록합니다.
- R2 실패도 트랜잭션 롤백 및 파일 배포 전 중단이므로 별도 복원 없이 R3를 실행할 수 있습니다.

적용 기능
- 바로가기/PWA 아이콘과 검색엔진 robots/sitemap 기본 구성
- 하위 서비스 검색 키워드, 검색주소, SEO 제목·설명 관리자 설정
- 검색 키워드 조회와 서비스별 고유 주소
- 서비스 즐겨찾기·최근 본 서비스·공유 기능
- 충전금 예치금과 수수료 공급가액·부가세 분리 원장
- 광고 서비스분야 타기팅과 동일 우선순위 내 최근 노출량 기준 공정 순환

운영 참고
- 검색 포털 등록과 검색 순위는 외부 포털의 심사·수집 결과이므로 배포만으로 즉시 보장되지 않습니다.
- 기존 원장은 LEGACY_UNSPLIT으로 보존하며 새 수수료 원장부터 VAT 포함 금액을 분리합니다.
- 즐겨찾기는 현재 브라우저 기준입니다. 로그인 계정 간 기기 동기화는 후속 확장 대상입니다.
