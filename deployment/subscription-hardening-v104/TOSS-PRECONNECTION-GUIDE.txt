수달 라이프 정기구독 결제 V104 운영 안내

1. 이 배포본은 토스 자동결제를 활성화하지 않습니다.
   SubscriptionPaymentGateway__Enabled=false 상태를 유지합니다.
2. 관리자는 기존처럼 은행 송금 후 관리자 화면에서 공급자 지급 완료를 처리합니다.
3. V104에서 적용되는 안전장치
   - 계약마다 고객이 동의한 결제수단을 고정하여 다른 기본 결제수단으로 임의 변경하지 않음
   - 신규 빌링키를 Data Protection으로 암호화해 DB에 저장
   - 한 계약 해지 시 고객 공용 결제수단을 삭제하지 않음
   - 결제 응답 불명확 시 주문번호로 조회한 후 같은 PG 시도키로 재확인
   - 확정 실패 재시도는 시도 번호를 올려 새 멱등키를 사용
   - 결제 취소·부분취소 웹훅을 원장과 결제상태에 반영
   - 원화 소수 금액을 거부하고 결제 완료일을 첫 청구 기준일로 고정
4. 토스 테스트 키 연결 전 확인
   - DataProtection__KeysPath가 서버 영구 경로이며 IIS 앱 풀 계정이 읽고 쓸 수 있어야 함
   - ClientKey와 SecretKey를 모두 보호된 Machine 환경변수로 등록
   - 테스트 카드로 빌링키 발급, 최초 결제, 재결제, 타임아웃 재조회, 부분취소, 전액취소, 해지를 검증
   - 검증 완료 전 Enabled를 true로 바꾸지 않음
5. Verify SQL의 legacy_unprotected_tokens가 0보다 크면 기존 데이터입니다.
   신규 등록 토큰은 암호화되며 기존 토큰은 별도 운영 전환 작업 후 암호화해야 합니다.
