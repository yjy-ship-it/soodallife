# V109 포털 링크·모바일 전체 메뉴

- 공급자 로고는 공급자 운영 홈으로 이동합니다.
- 공급자 알림은 공급자 알림센터로 이동합니다.
- 회사소개·약관·고객센터·공지사항·FAQ는 접속 중인 고객·공급자·관리자 레이아웃을 유지합니다.
- 고객과 공급자 화면에 반응형 전체 메뉴를 제공합니다.
- API와 데이터베이스는 변경하지 않습니다.

관리자 PowerShell에서 `D:\SOODALLIFE\Deploy-PortalNavigationV109.ps1`을 실행합니다.
배포 전 IIS 설정 및 세 정적 사이트 파일을 백업하며, 파일 교체 실패 시 자동 복원합니다.
