# 수달 라이프 신뢰도 정책 완성 v62

## 포함 내용

- 관리자 정책 초안 저장, 검토 승인, 운영 활성화, 새 버전 복제 API 연결 보강
- 서버 오류 로깅과 사용자용 오류 응답 개선
- 고객 평가 기본항목 6개 자동 등록
- 분쟁 귀책유형 5개, 제재유형 4개와 기본 점수표 자동 등록
- A/S 확정 이력 없음, 확정 분쟁 없음, 활성 제재 없음의 기준점수 100점 적용
- 고객 리뷰 등록 직후 활성 정책으로 신뢰도 자동 재산정
- 관리자 평가항목 및 귀책·제재 점수표 관리 화면
- 관리자와 공급자 화면의 `신뢰도 점수 산정 방식` 안내

## 배포 후 확인

1. 본사 관리자 계정으로 로그인합니다.
2. `신뢰도 정책`에서 `v1.0-draft`를 열어 기본 평가항목과 귀책·제재 점수표를 확인합니다.
3. `정책 초안 저장` → `검토 승인` → `운영 활성화`를 순서대로 한 번씩 실행합니다.
4. 공급자 상세에서 `활성 정책으로 재산정`을 누르면 해당 공급자 한 명이 현재 데이터로 즉시 다시 계산됩니다.
5. 새 고객 리뷰는 등록 직후 자동 재산정되므로 매번 관리자가 버튼을 누를 필요가 없습니다.

이번 변경은 기존 테이블을 사용하므로 별도 DB 마이그레이션을 실행하지 않습니다. API 시작 시 누락된 기본 기준 데이터만 중복 없이 등록됩니다.
