# V110 메뉴 이동·수달 케어 모바일 여백

- 고객·공급자·관리자에서 다른 메뉴를 선택하면 새 화면 최상단으로 이동합니다.
- 화면 이동 후 본문 영역으로 접근성 포커스를 이동합니다.
- 수달 케어 홈의 제목·설명·카드가 모바일 화면 가장자리에 붙지 않도록 공통 좌우 여백을 적용합니다.
- API와 데이터베이스는 변경하지 않습니다.

관리자 PowerShell에서 `D:\SOODALLIFE\Deploy-ViewportNavigationV110.ps1`을 실행합니다.
배포 전 IIS 설정 및 세 정적 사이트 파일을 백업하며, 파일 교체 실패 시 자동 복원합니다.
