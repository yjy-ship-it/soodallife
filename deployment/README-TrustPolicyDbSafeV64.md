# 수달 라이프 신뢰도 정책 운영 DB 안전 적용 v64

- 공급자 신뢰도 화면은 활성 정책 조회 결과가 비어 있어도 기본 6개 산정 항목과 산식을 표시합니다.
- `신뢰도 점수 산정 방식`에는 전체 산정 조건, 고객 리뷰 절차, 1~5점 환산식과 항목별 설명을 표시합니다.
- 기본 평가항목·귀책유형·제재유형은 API 시작 시 자동 등록하지 않습니다.
- 관리자가 `기본 정책 데이터 안전 등록`을 명시적으로 누를 때 SQL Server 트랜잭션으로 누락 데이터만 등록합니다.
- 정책 저장·승인·복제와 감사기록을 동일 트랜잭션으로 처리하고, 운영 SQL Server 감사기록은 파라미터 SQL로 저장합니다.
- v63 로그인/API 시작 복구를 포함한 누적 배포본이며 별도 DB 마이그레이션은 없습니다.

## 배포 후 순서

1. 관리자 로그인 → 신뢰도 정책 → `기본 정책 데이터 안전 등록`
2. 평가항목 6개, 귀책유형 5개, 제재유형 4개 표시 확인
3. `정책 초안 저장` → `검토 승인` → `운영 활성화`
4. 공급자 신뢰도 화면에서 6개 정책 설명과 상세 산정 방식 확인
