진행 범위:
1. 고객·전문가 PWA 분리
2. 서비스워커 캐시·업데이트 방식 보강
3. 오프라인 안내 화면
4. 설치·새 버전 안내
5. Push 구독 기반 구축
6. NICE 본인확인 연동
7. NHN 문자·알림톡·이메일 연동
8. NHN Web Push 연동
권장 방식은 다음 두 단계입니다.
- 1차: 1~5번 PWA 기반 완성 및 모바일 설치 테스트
- 2차: 6~8번 NICE·NHN 실제 연동 및 테스트 모드 검증
토스페이먼츠는 심사가 완료될 때까지 9번에서 대기하면 됩니다. 다만 결제 성공·실패 복귀 주소와 결제 화면 캐시 제외 처리는 PWA 작업 때 미리 준비할 수 있습니다.
실제 외부 발송 활성화에는 다음 자료가 필요합니다.
- NICE 사이트 코드·사이트 비밀번호 또는 API 인증정보
- NICE 운영 및 테스트 콜백 주소
- NHN Cloud 앱키·시크릿키
- SMS 발신번호 승인
- 알림톡 발신 프로필·템플릿 승인
- 이메일 발신 도메인과 발신주소 인증
- Push 앱 등록정보와 Web Push 사용 가능 여부
따라서 개발은 8번까지 진행하고, 토스페이먼츠만 심사 완료 후 연결하는 것이 최적의 순서입니다.
