# 수달 라이프 용어 표준

## 표시 용어

- 고객에게 서비스를 제안하거나 수행하는 회원은 모든 화면, 알림, 오류 안내, 운영 문서 및 약관에서 **전문가**로 표시한다.
- 법률 문서의 최초 정의는 `서비스 제공자(이하 “전문가”)`로 표기하고 이후에는 `전문가`를 사용한다.
- `전문가`라는 표시만으로 국가자격, 면허 또는 플랫폼의 품질 보증을 의미하지 않는다. 자격·면허가 필요한 서비스는 별도의 검증 정보와 상태를 표시한다.

## 내부 호환성

- 프로그램 내부 모델, 클래스, 필드, DB 테이블·컬럼, API 경로, 역할 코드, 오류 코드의 `Provider`/`PROVIDER` 명칭은 유지한다.
- 외부에 공개된 API 계약과 과거 데이터·감사 기록은 소급 변경하지 않는다.
- 기존 엑셀 기준자료의 `공급자 응답기한`, `공급자 공개` 열은 계속 읽을 수 있게 하고, 새 문서에는 `전문가 응답기한`, `전문가 공개`를 사용한다.

## 변경 금지 예시

- `ProviderProfile`, `ProviderId`, `RoleCodes.Provider`
- `/provider`, `/api/v1/provider/*`
- `PROVIDER_NOT_FOUND`, `PROVIDER_PROFILE_REQUIRED`
- 과거 EF 마이그레이션과 이미 기록된 거래·감사 이력
