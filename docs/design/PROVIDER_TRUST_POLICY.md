# 수달 라이프 전문가 신뢰도 운영정책

버전: 1.0  
적용 대상: 수달 라이프 전문가  
관리 주체: 본사 관리자

## 1. 목적과 기본 원칙

전문가 신뢰도는 고객에게 전문가의 거래 이행 수준을 이해하기 쉬운 점수와 등급으로 제공하고, 본사가 동일한 기준으로 품질을 관리하기 위한 지표다. 신뢰도는 100점 만점으로 산정하며, 확인되지 않은 신고나 단순 접수 사실만으로 감점하지 않는다.

- 실제 서비스 품질과 거래 이행에 관련된 구조화 데이터만 사용한다.
- 전문가 전체 승인 후 완료 거래 3건과 검증된 공개 리뷰 3건이 쌓여야 점수를 산정한다.
- 접수만 된 신고, A/S 또는 분쟁은 감점하지 않는다. 확정된 처리 결과, 최종 귀책 판정, 확정된 제재만 반영한다.
- 정책 기반 자동 산정과 관리자 조정은 모두 변경 이력과 감사 기록으로 남긴다.
- 기존 점수 이력은 수정하거나 삭제하지 않는다.

## 2. 평가 항목과 반영 비중

| 평가 항목 | 비중 | 평가 기준 |
| --- | ---: | --- |
| 인증·증빙 | 15점 | 전문가 승인, 서비스 승인, 필수 증빙 검증 및 유효기간 |
| 거래 이행 | 30점 | 완료율과 완료 증빙 등록 여부 |
| 고객 평가 | 30점 | 완료 거래에 연결된 검증·공개 리뷰의 평가 항목 |
| A/S | 10점 | 종결된 A/S의 해결 여부, 재발 여부, 분쟁 전환 여부 |
| 분쟁 | 10점 | 본사에서 확정한 구조화 귀책 판정 |
| 정책 준수 | 5점 | 확정된 제재 유형과 현재 유효한 제재 |

각 항목의 세부 산식과 가중치는 본사 관리자에 등록된 활성 정책 버전을 사용한다. 화면이나 프로그램 코드에 점수 값을 별도로 고정하지 않는다.

## 3. 등급

| 점수 | 등급 |
| ---: | --- |
| 90~100점 | 명예수달 |
| 80~89.9999점 | 우수수달 |
| 70~79.9999점 | 믿음수달 |
| 60~69.9999점 | 안심수달 |
| 0~59.9999점 | 새싹수달 |
| 산정 요건 미충족 | 신규·평가중 |

## 4. 본사 관리자 운영 절차

정책은 `초안(DRAFT) → 검토 승인(APPROVED) → 운영 활성화(ACTIVE) → 운영 종료(RETIRED)` 순서로 관리한다.

1. 초안에서 최소 표본 수, 항목별 가중치와 산정 규칙을 검토한다.
2. 가중치 합계가 100인지 확인하고 정책을 승인한다.
3. 시행일과 기존 활성 정책의 기간이 겹치지 않는지 확인한 뒤 활성화한다.
4. 정책 변경이 필요하면 활성 정책을 직접 수정하지 않고 새 버전으로 복제해 검토한다.
5. 전문가별 상세 화면에서 활성 정책으로 재산정할 수 있다.
6. 예외 조정이 필요한 경우 0~100점 사이의 점수와 구체적인 근거를 입력한다. 조정 전·후 점수, 처리 관리자, 처리 시각과 사유는 변경 이력에 기록한다.

## 5. 전문가 공개 및 이의 확인

전문가 화면에는 현재 점수, 등급, 산정 상태, 등급 기준, 적용 정책 버전, 항목별 반영 결과와 변경 이력을 표시한다. 산정 요건이 부족하면 부족한 완료 거래·검증 리뷰 수 또는 필요한 근거를 안내한다. 관리자가 조정한 경우에도 조정 사유와 변경 결과를 이력에서 확인할 수 있어야 한다.

## 6. 데이터 및 감사 원칙

- 모든 산정 결과는 당시 정책과 근거 데이터의 스냅샷을 보관한다.
- 동일 요청은 중복 처리되지 않도록 요청 키를 사용한다.
- 시뮬레이션은 실제 점수와 변경 이력에 영향을 주지 않는다.
- 관리자 재산정과 조정 API는 본사 관리자 권한에서만 사용할 수 있다.
- 점수 변경 이벤트는 추가만 허용하며 수정·삭제를 금지한다.
