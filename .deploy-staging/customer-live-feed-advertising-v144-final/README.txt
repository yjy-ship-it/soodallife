Soodal Life V144 - Customer Live Activity Feed Advertising

적용 내용
- 고객 홈의 "전국에서 지금 진행 중인 서비스"에 실제 거래와 구분되는 광고 행을 섞어 표시합니다.
- 실제 거래는 최신순 30건을 유지하고, 광고는 4·10·16번째 실제 거래 다음에 최대 3건 표시합니다.
- 광고에는 항상 "광고" 문구를 표시하며 실제 거래 건수와 순번에는 포함하지 않습니다.
- 지역 필터와 현재 거래 지역을 이용해 시·도 타깃 광고를 조회합니다.
- 동일 공급자 광고는 한 화면에서 한 번만 표시합니다.
- 광고가 화면에 50% 이상 1초간 보일 때만 노출을 기록하며 클릭은 별도 기록합니다.
- 공급자 광고 신청 화면과 관리자 캠페인 관리에 "고객 실시간 서비스 목록" 노출 위치가 추가됩니다.

초기 정액 요금
- 7일: 28,000원
- 14일: 48,000원
- 30일: 88,000원
- 시·도 1곳당 10,000원, 시·군·구 1곳당 2,000원, 지역 가산 상한 30,000원

검증 결과
- Frontend TypeScript/production build: passed
- 광고 콘텐츠·공급자 캠페인 관련 API 테스트: 20 passed
- 전체 백엔드 테스트의 기존 인테리어 테스트 및 테스트 인프라 경고는 이번 변경과 별개로 남아 있습니다.

배포
1. ZIP과 Deploy-CustomerLiveFeedAdvertisingV144.ps1을 D:\SOODALLIFE에 복사합니다.
2. 관리자 권한 PowerShell에서 실행합니다.
   D:\SOODALLIFE\Deploy-CustomerLiveFeedAdvertisingV144.ps1 -ConfirmProductionDeployment
3. 스크립트가 DB·IIS·앱 파일을 백업하고 DB 적용, API/고객/공급자/관리자 앱 배포와 검증을 수행합니다.

복원
- IIS 구성, API와 각 웹앱 파일, 운영 DB 백업을 배포 전에 자동 생성합니다.
- 파일 배포 실패 시 앱 파일을 자동 복원합니다.
- DB 문제 시 출력된 .bak 파일을 사용해 운영 절차에 따라 복원합니다.
