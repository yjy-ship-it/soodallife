V117 공급자 광고 신청·미리보기

- 광고 종료일은 선택한 7·14·30일 기간을 기준으로 자동 계산해 표시합니다.
- 수달 라이프 내부 화면은 고객 홈, 전체 서비스, 수달 케어, 수달 인테리어, 공지사항 중에서 선택합니다.
- 외부 웹사이트는 http/https 전체 주소를 입력하며 게시 광고의 버튼에서 새 창으로 열립니다.
- 연결 화면이 있으면 버튼 문구가 필수입니다.
- 공급자는 실제 광고 카드, 기간, 이동 대상을 미리 확인하고 확인 체크 후 신청합니다.
- 고객 홈에 표시되는 광고에는 자세히 보기 버튼과 노출·클릭 기록이 연결됩니다.
- 데이터베이스 스키마 변경은 없습니다.
