수달 라이프 v120 공급자 광고·소개·채팅 상담 배포본

변경 내용
- 광고 연결 방식의 "수달 라이프 내부 화면"을 "공급자 소개 화면"으로 변경
- 상세 설명, 기본정보, 완료 실적, 신뢰도, 서비스, 공개 리뷰를 고객용 공급자 소개 화면에 표시
- 기존 공급자 광고의 내부 링크도 실행 시 공급자 소개 주소로 안전하게 변환
- 고객의 채팅 상담 신청 시 전용 1:1 채팅방 생성 및 중복 생성 방지
- 공급자 WEB 알림 즉시 기록, KAKAO 알림톡은 외부 채널 계약·설정 활성화 후 발송 대기

배포 전
1. 서버의 ZIP SHA-256을 확인합니다.
2. 관리자 PowerShell에서 루트 Deploy-ProviderAdvertisingConsultationV120.ps1을 실행합니다.
3. -ConfirmProductionDeployment 스위치가 반드시 필요합니다.
4. 배포 스크립트는 IIS와 DB 백업을 만든 후 변경을 적용합니다.

주의
- 카카오 알림톡 실제 발송은 외부 업체 계약, 승인 템플릿, 채널 자격증명과 설정이 모두 활성화된 뒤 동작합니다.
- 현재 미연동 상태에서는 수달 내부 WEB 알림과 채팅은 정상 생성되고 KAKAO 발송은 건너뜁니다.
